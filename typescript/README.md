# TypeScript Practice Environment

## Available Scripts

- **`npm run dev`**: Automatically runs `src/index.ts` in watch mode (updates immediately on save).
- **`npm run run`**: Runs `src/index.ts` once directly using `tsx`.
- **`npm run build`**: Compiles TypeScript into JavaScript inside the `dist/` directory.
- **`npm start`**: Runs the compiled JavaScript file from `dist/index.js`.

## Project Structure

```
├── src/
│   └── index.ts        # Main practice file
├── dist/               # Compiled JavaScript files (generated after build)
├── tsconfig.json       # TypeScript compiler configuration
├── package.json        # Dependencies and practice scripts
└── .gitignore
```
